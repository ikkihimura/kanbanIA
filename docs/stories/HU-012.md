# HU-012 — Servicio local autenticado

Hito: M2

Dependencias: 002,009

Responsable recomendado: agent-integration-engineer + rust-engineer

## Historia

Como usuario quiero que integraciones locales operen sobre el mismo tablero.

## Criterios de aceptación

- [ ] CA-1: Host desktop expone API solo loopback, con puerto dinámico y token en descriptor protegido; sin credenciales en logs.
- [ ] CA-2: Toda ruta autentica y restringe proyecto; rechazar orígenes no permitidos y cargas excesivas; sin SQL ni shell genérico.
- [ ] CA-3: API llama a slices existentes; aplicación cerrada produce error claro y no inicia otro propietario de datos.

## Verificación requerida

Contrato autenticado/no autenticado, proyecto ajeno, token inválido y dos arranques; revisión security-reviewer obligatoria.
