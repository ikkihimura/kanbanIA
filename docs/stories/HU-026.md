# HU-026 — Node para los adaptadores al abrir desde Finder

Hito: M4

Dependencias: 019,021

Responsable recomendado: desktop-ui-engineer + agent-integration-engineer

## Historia

Como usuario nuevo quiero que los agentes funcionen aunque abra Kanban IA desde Finder o el menú Inicio, o que la app me diga exactamente qué falta.

Contexto (HU-019/021): los adaptadores npm (`claude-agent-acp`, `codex-acp`) son scripts con `#!/usr/bin/env node`. Con Node instalado por nvm, una app abierta desde Finder no tiene ese `PATH` y el adaptador no arranca; hoy se documenta abrirla desde una terminal.

## Criterios de aceptación

- [ ] CA-1: «Comprobar adaptador» distingue «no encuentro node» de otros fallos y explica cómo resolverlo.
- [ ] CA-2: Opción decidida por el propietario: ruta de `node` configurable (validada en disco como la del adaptador) que se antepone al `PATH` del proceso, o detección de instalaciones habituales; nunca se ejecuta una shell de login del usuario para averiguarlo.
- [ ] CA-3: Verificado abriendo la app empaquetada desde Finder con Node de nvm: Claude Code y Codex arrancan; guía actualizada (docs/AGENTES.md).

## Verificación requerida

Prueba con el agente falso y un `PATH` sin node; prueba manual con la `.app` desde Finder; `npm run check`; revisión security (la ruta configurada no amplía el entorno permitido).
