Hito: M3

Dependencias: 017

Responsable recomendado: agent-integration-engineer

## Historia

Como usuario quiero ejecutar tareas separadas sin mezclar sus cambios.

## Criterios de aceptación

- [ ] CA-1: Crear worktree y rama únicos desde referencia explícita; no modificar ni limpiar cambios del repositorio original.
- [ ] CA-2: Supervisor inicia argumentos explícitos, aplica concurrencia máxima, captura salida acotada y cancela árbol de procesos según sistema.
- [ ] CA-3: Reinicio marca ejecuciones no verificables interrupted; no relanza automáticamente; limpieza nunca elimina worktree con cambios sin acción explícita.

## Verificación requerida

Proceso falso prueba salida, fallo, timeout, cancelación e hijos; repositorio sucio; rutas con espacios; evidencia macOS y Windows.
